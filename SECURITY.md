# Security policy

## Reporting a vulnerability

Please use GitHub's **private vulnerability reporting** feature for this repository when it is enabled. Do not disclose an exploitable vulnerability in a public issue.

If private vulnerability reporting is unavailable, open a minimal public issue asking for a private contact route. Do not include exploit details, credentials, personal data or proprietary game files in that issue.

## Scope

Reports are most useful when they identify:
- the affected source file or component;
- the relevant commit or release;
- the Android/API/ABI environment, with identifying device details redacted;
- reproducible steps and a minimal, sanitized log excerpt;
- the likely security impact.

## Do not include

Never attach original game discs, executable files, proprietary game data, generated lifted code, save files, diagnostic archives containing unredacted personal information, access tokens or signing keys.

This project is experimental. Do not assume that an APK build or a successful diagnostic test implies that the full game port is secure or production-ready.
