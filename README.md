# The Movies for Android

Unofficial ARM64 Android port of *The Movies* (2005).

**Status:** Work in progress. The goal is a fully playable Android version. Builds are experimental until the game has been tested in-game on a device.

## Build

See **[Build the APK](docs/ANDROID-BUILD.md)** for the required tools and build steps.

You need your own legally obtained copy of the original game. Game files and generated game code are not included in this repository.

## Project

- Android: ARM64, Vulkan 1.1.
- Current target: Russian CD release 1.1.
- A Steam-version port is planned after the Android version.
- This is an unofficial community project and is not affiliated with the original rights holders.
